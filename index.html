Репутация файлов

По желанию отправляется только SHA-256 через наш API в VirusTotal и MalwareBazaar (только сервисам с введённым ключом). Содержимое файла не отправляется. Хеш может раскрыть, какой известный файл вы проверяете. Ключ хранится только до закрытия или перезагрузки страницы.

Кеш: 6 часов. VirusTotal → MalwareBazaar: следующий сервис при отсутствии обнаружений или ошибке. До одного запроса за 16 секунд в этой вкладке. Нулевое число обнаружений не отменяет локальную проверку. Бесплатный API имеет ограничения использования.

Для теста отправляется SHA-256 пустого файла. Кеш не используется.

База SHA-256

Дополнительная пользовательская база хешей. Импортируйте JSON из доверенного источника: массив объектов с полями sha256 и name. Совпадение означает совпадение с вашей базой; её достоверность определяет источник.

Проверка использует снимок базы на момент добавления файла.

Адаптивная нагрузка

От 1 до 3 анализов по результату теста SHA-256, скорости и задержкам интерфейса. Полная загрузка Android и свободная оперативная память недоступны браузеру. При снижении лимита уже начатые проверки завершаются.

Пределы проверки

ZIP: до 2 вложенных уровней, общий лимит 500 записей, 32 МиБ на запись и 128 МиБ суммарно, степень сжатия до 200×. ZIP64, шифрование ZIP и другие форматы сжатия не поддерживаются. APK: двоичный манифест и таблицы DEX; подписи и поведение кода не проверяются. YARA и структурный анализ: до 32 МиБ на файл. Более крупные файлы хешируются потоково, пропуски указаны в отчёте. Эвристики могут ошибаться. Проверка при закрытии вкладки прекращается; Android может приостановить её в фоне.

Движок YARA 4.5.8. Malpedia загружается частями по формату файла. Резервная база: 8 правил. Совпадения не доказывают выполнение вредоносного кода. EICAR — безвредный тестовый образец, не настоящий вирус.

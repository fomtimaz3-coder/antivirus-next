# Anti-wiew 2.0.0

Локальный статический сканер для браузера Android. Нет сервера обработки файлов. Не полноценный антивирус и не защита ОС.

## Запуск и тесты

`python3 -m http.server 3000` в каталоге проекта. Production требует HTTPS.

`node tests.mjs` и `node extended-tests.mjs`.

Vercel: framework Other, без команды сборки, корень содержит index.html. Репозиторий mobile-desktop, ветка anti-wiew. Публикация через Vercel plugin в существующий проект; main остаётся прежним.

## Возможности

- Две темы, три акцента, компактность, полупрозрачное мобильное меню, круговой прогресс, цвет и текст результата.
- Множественный выбор, потоковый SHA-256, EICAR, статические эвристики, пользовательская хеш-база.
- Адаптивный планировщик начинает с одного Worker и повышает лимит при отзывчивом интерфейсе, ограничиваясь 1–3 потоками по hardwareConcurrency/deviceMemory. При отсутствии deviceMemory консервативный предел 1. Скорость и задержки определяют дальнейший лимит; уже начатые работы не обрываются. Полная загрузка Android и свободная RAM недоступны.
- ZIP: методы Store/Deflate, контроль CRC и заголовков, хеши и сигнатуры содержимого. Один уровень, максимум 500 записей, 32 МиБ на запись, 128 МиБ распакованных данных, степень сжатия до 200×. Каталог до 8 МиБ. ZIP64, многотомные и зашифрованные записи не поддерживаются. Пропуски видны в отчёте.
- APK: двоичный AndroidManifest.xml до 2 МиБ; пакет, версия, SDK, разрешения и пояснения. Нет проверки подписи, поведения DEX, ресурсов или всех вариантов XML. Разрешения не означают вредоносность.
- Итоговые категории с фильтрами, поиск по имени/дате, простой отчёт с раскрываемыми техническими данными.
- EICAR self-test, PWA manifest, offline Service Worker, обновления по version.json.
- История IndexedDB, выборочное удаление, срок 7/30/90 дней или бессрочно, экспорт JSON, объём данных. Очистка по сроку при старте и изменении настройки.

## Ограничения

Актуальной встроенной базы вредоносного ПО нет. Признаки не гарантируют обнаружение, отсутствие находок не доказывает безопасность. Обфускация, неподдерживаемые кодировки и контейнеры дают пропуски. Время — оценка, не обещание. ОС может приостановить браузер. Офлайн работает только после успешного кеширования; обновления требуют сеть. Очистка данных браузера удаляет историю и кеш.

## Верификация

Тесты SHA-256, EICAR и границ блоков; ZIP Store/Deflate, повреждённого CRC, шифрования, неподдерживаемого метода и лимита распаковки; синтетического валидного двоичного манифеста APK; категорий итогов и адаптивного планировщика. В опубликованном браузере проверен self-test → результат → история; офлайн-кеш и установка доступны. Физический Infinix SMART 8 HD и отключение сети на устройстве не проверялись.

## Обновления

Меняйте VERSION в app.js, версию в version.json и имя CACHE в sw.js одновременно. Service Worker устанавливает атомарный набор приложения; новая версия активируется по кнопке обновления после завершения проверок. Файлы пользователя никогда не входят в кеш приложения.
